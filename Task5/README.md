
# Завдання 5: Керування конфігурацією за допомогою Ansible



Згідно з базовими стандартами розробки сценаріїв Ansible, архітектура побудована на декларативному синтаксисі мови YAML:



1. **Структура Playbook:** Сценарій починається з трьох дефісів (`---`) і є списком словників (Plays). Кожен Play визначає цільові хости (`hosts: all`) та адміністративні привілеї (`become: true`).

2. **Списки (Lists):** Елементи, які починаються з дефіса з пробілом (`- name:`), позначають послідовні кроки виконання.

3. **Словники (Dictionaries/Maps):** Пари `ключ: значення` використовуються для передачі параметрів модулям (наприклад, `state: present`).

4. **Формат параметрів:** Усі завдання переведені на чистий YAML-формат словників. Застарілий та важкочитний стиль однорядкових аргументів `key=value` повністю виключений з коду.
